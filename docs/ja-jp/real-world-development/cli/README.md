**[GitHub Copilot CLI][about-copilot-cli]** は、エージェント型コーディング アシスタントの GitHub Copilot をターミナルで利用できるようにします。コードベースを探索し、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンド ラインから行えるため、グラフィカル エディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys で一連の作業を進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、基本を確認します。
2. 星評価を表示する小さな変更を加え、ブラウザーで確認して、最初のプルリクエスト (PR) を手動でマージします。
3. フィルター機能の issue から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示ファイルを更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルターの動作を確認します。
7. 品質保証 (QA) のカスタム エージェントを作成し、要件、カバレッジ、検証の証拠を確認します。
8. フィルター機能の変更全体をレビューし、Agent Merge を使ってフィルター機能の PR を処理します。
9. コンテキスト、モデル、共有、クラウド エージェントへの任意の委任に使えるスラッシュ コマンドを確認します。

ワークショップの内容に集中できるよう、PR は 2 つ作成します。1 つは星評価、もう 1 つはフィルター機能です。後者には指示ファイルとスキルの更新、QA プロファイル、テストが含まれます。フィルターと品質の作業では同じ会話とブランチを使うため、各ツールを試しながら作業を続けられます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかの有効なプランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンド ライン操作の基本的な知識

> [!TIP]
> 有料プランがありませんか。認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使う場合は、管理者が Copilot CLI を有効にしていることを確認してください。
